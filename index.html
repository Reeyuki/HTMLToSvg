How it works
  1. Upload your .html file and click Generate SVG
  2. Download the result — save it as index.svg
  3. Commit index.svg to your GitHub repository
  4. Replace placeholders in the CDN mirror URLs above
  5. Done — the SVG loads your HTML via an embedded iframe
