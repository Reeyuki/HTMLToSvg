How it works
  1. Upload your .html file and fill in your GitHub details
  2. Set a filename, then generate and download the SVG
  3. Commit the .svg file to your GitHub repository
  4. Use one of the CDN links above to load it
Limits jsDelivr's GitHub cap is around 20 MB per file. Base64 adds roughly 33% overhead, so keep source HTML under ~15 MB.
