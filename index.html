HTML to SVG Converter

Wrap an HTML file into a self-loading SVG so it can be served through GitHub-backed CDNs. Follow the numbered steps below in order, including creating the repo if you don't already have one.
1
Do you already have a GitHub repository?
This is a folder on GitHub.com that will hold the generated file. If you already have one you want to use, skip to step 2. Otherwise, create one now:
Open github.com/new to create a repository ↗
  1. Type any Repository name, e.g. my-svgs
  2. Set visibility to Public. The CDN links in step 6 will not work on a Private repo
  3. Leave everything else as default and click Create repository
  4. You'll land on the empty repo page. Keep that tab open, you'll upload to it in step 6

6
Upload it to GitHub and copy a link
You do not need git installed for this. Do it straight from the GitHub website:
  1. Go to your repo page on GitHub (the one from step 1)
  2. If it's the folder from your Path field, open that folder first. Otherwise stay at the top level
  3. Click Add file → Upload files (top right of the file list)
  4. Drag in the index.svg file you just downloaded, not the original .html file
  5. Scroll down and click Commit changes
  6. Wait about a minute, then click one of the links below

Quick recap
  1. Create a public GitHub repo, or use one you already have (step 1)
  2. Pick your .html file (step 2)
  3. Paste that repo's URL (step 3)
  4. Name the output file (step 4)
  5. Generate, then download the .svg (step 5)
  6. Upload that .svg to the repo through GitHub's website, then use a link above (step 6)
Limits & troubleshooting jsDelivr's GitHub cap is around 20 MB per file. Base64 adds roughly 33% overhead, so keep source HTML under ~15 MB. A repo must be Public for the CDN links to work. If a link 404s, wait a minute and retry, and double-check the file was actually committed to the branch and path you entered in step 3.
