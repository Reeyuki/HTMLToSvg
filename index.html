How it works
  1. Upload your .html file and fill in your GitHub details
  2. Set a custom filename, then click Generate SVG and download
  3. Commit the .svg file to your GitHub repository
  4. Use the CDN mirror URLs generated above
  5. Done — the SVG loads your HTML via an embedded iframe
⚠ Limits
jsDelivr GitHub cap: ~50 MB per file  /  Base64 bloat: ~33%  /  Keep source HTML under 35 MB
